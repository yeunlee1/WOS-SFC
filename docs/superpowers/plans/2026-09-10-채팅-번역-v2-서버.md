# 채팅 v2 — 서버 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 서브에이전트는 쓰지 않는다(빌드·테스트 경합).

**Goal:** 채팅 번역 엔진을 OpenAI(Responses API, 구조화 출력)로 바꾸고, 서버가 메시지마다 접속자가 보고한 대상 언어로 한 번에 번역해 `chat:translation`으로 밀어 주며, 히스토리에 번역을 동봉하고 배치 엔드포인트를 제공한다. 감사 A·C에서 확정된 게이트웨이 결함(ack 부재, 입퇴장 폭주, 캐시 저장 실패, 죽은 엔드포인트)을 함께 고친다.

**Architecture:** `translate` 모듈이 엔진(OpenAI)·용어집 선택·스크립트 판별·전역 번역 큐·사용량 카운터·`MessageTranslationsService`(새 테이블)를 갖고 `ChatTranslationService`를 export한다. `chat` 모듈의 게이트웨이는 소켓별 대상 언어를 유지하고, 저장·방송 직후 fire-and-forget으로 번역을 큐에 넣어 결과를 emit한다. 게시글용 단건 `POST /translate`는 같은 엔진 위에 텍스트 해시 캐시로 유지된다.

**Tech Stack:** NestJS 11, TypeScript, `openai` npm(Responses API), TypeORM(MySQL, 마이그레이션 SQL), Jest.

**Spec:** `docs/superpowers/specs/2026-09-10-채팅-번역-v2-design.md`. 감사 근거: `클로드 출력물/2026-09-09-wos-오케스트레이션/보고서-A-채팅감사-서버.md`, `보고서-C-채팅감사-흐름계약.md`(항목 A-n, C-n으로 인용).

```typescript
// 문자 스크립트로 원문 언어를 어림잡는다. 확실한 경우(한글·가나·키릴 단일)에만 번역을 건너뛰는 데 쓴다.
export type Script = 'ko' | 'ja' | 'ru' | 'han' | 'latin' | 'mixed' | 'none';
export type Lang = 'ko' | 'en' | 'ja' | 'zh' | 'ru';
export const TARGET_LANGS: Lang[] = ['ko', 'en', 'ja', 'zh', 'ru'];

const RE = {
  hangul: /[가-힣ᄀ-ᇿ㄰-㆏]/g,
  kana: /[぀-ゟ゠-ヿ]/g,
  han: /[一-鿿㐀-䶿]/g,
  cyrillic: /[Ѐ-ӿ]/g,
  latin: /[A-Za-zÀ-ɏ]/g,
};
const count = (re: RegExp, t: string) => (t.match(re) ?? []).length;

export function hasLetters(text: string): boolean {
  return Object.values(RE).some((re) => count(re, text) > 0);
}

export function detectScript(text: string): Script {
  const h = count(RE.hangul, text), k = count(RE.kana, text), z = count(RE.han, text), c = count(RE.cyrillic, text), l = count(RE.latin, text);
  const kinds = [h > 0, k > 0 || (k > 0 && z > 0), z > 0 && k === 0, c > 0, l > 0].filter(Boolean).length;
  if (h + k + z + c + l === 0) return 'none';
  if (kinds > 1) return 'mixed';
  if (h > 0) return 'ko';
  if (k > 0) return 'ja';
  if (z > 0) return 'han';
  if (c > 0) return 'ru';
  return 'latin';
}

export function unambiguousLang(text: string): 'ko' | 'ja' | 'ru' | null {
  const s = detectScript(text);
  return s === 'ko' || s === 'ja' || s === 'ru' ? s : null;
}

export function effectiveLang(language?: string | null): Lang {
  return (TARGET_LANGS as string[]).includes(language ?? '') ? (language as Lang) : 'en';
}
```

가나+한자 조합은 `ja`로 봐야 한다 — `kinds` 계산에서 한자는 가나가 있을 때 별도 종류로 세지 않는다(위 코드의 세 번째 항). 테스트가 통과할 때까지 이 조건을 다듬는다.
