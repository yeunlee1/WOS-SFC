# 동화 버전 UI 설계 (2026-09-02)

## 목표

지금 프론트를 그대로 둔 채, `/story` 주소로 들어오면 **수채화 그림책** 결의 완전히 다른 UI/UX가 뜨는 두 번째 경험 레이어를 만든다. 같은 서버, 같은 로그인, 같은 실시간 데이터를 쓴다. 시안은 디자인 캔버스 "WOS 동화책 시안"(입구·전투현황·커뮤니티·채팅 4화면)이고 사용자가 "이대로" 승인했다.

## 원칙

- **기존 앱은 손대지 않는다.** 유일한 변경은 `web/src/main.jsx`의 진입 분기와 `web/src/App.jsx`로 옮기는 `style.css` import 한 줄이다. 두 앱은 서로의 CSS를 로드하지 않는다(React.lazy 로 청크가 갈린다).
- **엔진은 재사용, 껍데기는 새로 쓴다.** 카운트다운 오디오 절대예약, 시계 동기화, 소켓, 집결 그룹, 채팅 번역 큐, 게시판 업로드처럼 정밀도와 회귀 위험이 큰 로직은 기존 컴포넌트(`Countdown`, `PersonalPanel`, `RallyGroupPanel`, `CountdownDots`, `RallyDots`, `Noticeboard`, `AllianceNoticeboard`, `Board`, `ChatTab`, `OnlinePanel`, `OperationBoardTab`, `AdminTab`)를 그대로 끼워 넣고, 그 클래스 이름을 `story.css`가 새로 입힌다. 입구, 레일, 상단바, 화면 구성, 카드 프레임, 타이포, 색, 질감, 전환은 새 코드다.
- **카운트다운 숫자는 대비를 지킨다.** 종이색 바탕에 진한 잉크색(#2f2a3f) 숫자. 파스텔은 배경·여백·테두리에만 쓴다.
- **모바일 반응형 필수.** 768px 이하에서 레일은 하단 바로, 책 펼침은 한 페이지로, 2열은 1열로.

## 구조

```
web/src/
├── main.jsx            # resolveEntry(pathname) 로 App 또는 StoryApp 을 lazy 로드
├── entry.js            # resolveEntry — '/story' 접두어면 'story', 아니면 'main'
├── App.jsx             # 기존 그대로 + `import '../style.css'` 한 줄 추가
└── story/
    ├── StoryApp.jsx        # 세션 복원·소켓·시계 동기화 부트스트랩(App.jsx 와 같은 effect), 입구 ↔ 껍데기 분기
    ├── StoryEntrance.jsx   # 펼쳐진 책 위 로그인·가입 (AuthModal 의 핸들러와 검증 규칙을 그대로)
    ├── StoryShell.jsx      # 책갈피 레일 + 상단바 + 본문 프레임 + 접속 중 패널
    ├── StoryTopbar.jsx     # UTC 시계, 동기화 배지, 음성 켬/끔·볼륨, 언어, 사용자 칩·로그아웃
    ├── StoryRail.jsx       # 탭 내비게이션 (전투현황·작전판·커뮤니티·채팅·관리자[developer])
    ├── StoryBattle.jsx     # Countdown + PersonalPanel + RallyGroupPanel + 두 타임라인 조합
    ├── StoryCommunity.jsx  # 색인 탭(공지사항·KOR·NSL·JKY·GPX·UFO), 연맹 탭은 공지·게시판 2열
    ├── icons.jsx           # 스트로크 SVG 아이콘 (이모지 대신)
    ├── story.css           # 동화 버전 전체 스타일 (재사용 컴포넌트 클래스 포함)
    └── __tests__/          # entry, entrance, shell 테스트
```

## 화면별 결정

| 화면 | 새로 쓰는 것 | 재사용하는 것 |
|---|---|---|
| 입구 `/story` (로그인 전) | 물감 하늘·언덕·성·눈송이 배경, 펼쳐진 책 2페이지(왼쪽 브랜드·오른쪽 폼), 가입 전환, 연맹 칩 | `api.login/signup`, `setUser`, `changeLang`, `warmupRallyAudio`, 닉네임 정규식·비밀번호 규칙 |
| 껍데기 | 책갈피 레일, 상단바, 본문 프레임, 접속 중 패널 배치, 모바일 하단 바 | `useSocket`, `useReadyProbe`, `clockSync startup/shutdown/syncTime`, `api.getMe`, `auth:expired` 처리, `OnlinePanel` |
| 전투현황 | 2열 배치(왼쪽 카운트다운·타임라인, 오른쪽 내 행군·집결 그룹), 카드 프레임 | `Countdown`(숫자·프리셋·시작/중지·키보드), `PersonalPanel`, `RallyGroupPanel`, `CountdownDots`, `RallyDots` |
| 커뮤니티 | 색인 탭 모양, 연맹 탭에서 공지·게시판 2열 동시 표시 | `Noticeboard`, `AllianceNoticeboard`, `Board` |
| 채팅 | 프레임과 말풍선 스타일 | `ChatTab` 전체(사이드바 포함) |
| 작전판·관리자 | 프레임만 | `OperationBoardTab`, `AdminTab` |

`RallyTimer`, `Dispatch`, `OnlineList`는 현재 앱 어디에서도 렌더되지 않는 죽은 컴포넌트다. 시안에는 그렸지만 동화 버전에도 넣지 않는다(기능을 되살리는 것은 별도 결정).

## 디자인 토큰

- 종이 `#fbf6ee`, 잉크 `#3f3a4a`, 진한 잉크(숫자) `#2f2a3f`, 흐린 글씨 `#8a8298`
- 파스텔 — 하늘 `#cfe3f5`, 민트 `#d3ede0`, 살구 `#f7c9b3`, 라벤더 `#e2d8f3`, 버터 `#f7ecc4`, 장미 `#f5d6dd`
- 연맹 색 — KOR 하늘, NSL 민트, JKY 버터, GPX 라벤더, UFO 장미
- 글꼴 — 제목 Gowun Batang, 본문 Gowun Dodum, 손글씨 Gaegu (Google Fonts, 폴백 시스템 고딕). 첫 배포 뒤 자체 호스팅으로 바꿀 수 있다.
- 종이 질감 — SVG feTurbulence 오버레이. 물감 — blur 된 원형 그라디언트 + multiply.
- 손그림 테두리 — 비대칭 border-radius(`22px 16px 24px 14px / 14px 24px 16px 22px`), 2px 잉크 선, 살짝 기울인 카드(±0.4deg).

## 검증

- Vitest — `resolveEntry`, `StoryEntrance`(검증 메시지·로그인 호출·가입 호출), `StoryShell`(탭 전환·developer 만 관리자 탭·로그아웃).
- 빌드 — `npm run build --workspace web` 후 `dist/assets`에 story 청크와 CSS가 분리됐는지, `index.html`이 `story.css`를 미리 로드하지 않는지.
- 실제 화면 — 로컬 서버(검증용 MySQL 3307)와 Vite 개발 서버를 띄우고 Playwright로 `/story` 입구, 가입, 전투현황, 커뮤니티, 채팅, 작전판을 데스크톱(1440)과 모바일(390) 폭에서 스크린샷으로 확인한다.
- 기존 앱 — `/`가 이전과 같이 뜨고 기존 웹 테스트 226건이 그대로 통과한다.

## 보증하지 못하는 것

실기기 음성 정렬(로직 미변경이라 기존과 같아야 하지만 실측은 못 함), 100명 부하, Google Fonts 차단 환경에서의 글꼴(폴백으로 표시됨).
